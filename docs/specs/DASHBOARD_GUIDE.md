## 1. Apa Itu Dashboard?

Dashboard adalah **CMS (Content Management System)** atau alat untuk mengelola konten website. Anda bisa:

| Tanpa Dashboard | Dengan Dashboard |
|-----------------|------------------|
| Butuh developer untuk update | Update sendiri, kapan saja |
| 1-2 hari proses update | 5 menit update selesai |
| Biaya tambahan per update | Free jika update sendiri |

### Cara Kerja Dashboard

```
1. Anda login ke https://yourdomain.com/admin
2. Pilih menu: Portfolio / News / Competition
3. Klik "Tambah Baru" atau "Edit"
4. Isi data + upload gambar
5. Klik "Save"
6. Website otomatis terupdate!
```

## 3. Menu & Fungsi Dashboard

### Menu 1: Portfolio
**Pokoknya: Tampilkan karya event yang sudah dikerjakan**

#### Cara Tambah Portfolio Baru:
1. Klik menu **Portfolio** > **All Items**
2. Klik tombol **"+ Tambah Item"**
3. Isi Form:
   - **Gambar**: Klik upload, pilih foto event (max 5MB)
   - **Judul**: Nama event (contoh: "Garden Romance Wedding")
   - **Kategori**: Pilih dari dropdown (Wedding/Corporate/Exhibition/Private)
   - **Lokasi**: Kota event (contoh: "Jakarta")
   - **Tahun**: Tahun event dilangsungkan
   - **Deskripsi**: Teks singkat tentang event (opsional)
4. Klik **"Simpan"**

#### Cara Edit Portfolio:
1. Di halaman "All Items", klik ikon **Edit** pada item yang ingin diubah
2. Rubah data yang perlu diubah
3. Klik **"Update"**

#### Cara Hapus Portfolio:
1. Klik ikon **Hapus** pada item
2. Konfirmasi dengan klik **"Ya, Hapus"**

---

### Menu 2: News / Blog
**Pokoknya: Posting berita, pengumuman, kompetisi**

#### Tip:
> Gunakan News untuk:
> - Pengumuman pemenang kompetisi
> - Review event yang baru dilangsungkan
> - Tips & Trick event planning
> - Promo khusus

#### Cara Tambah News:
1. Klik menu **News** > **All Articles**
2. Klik **"+ Tulis Artikel Baru"**
3. Isi:
   - **Judul**: Singkat dan menarik
   - **Slug**: URL otomatis (bisa diubah, contoh: `garden-wedding-promo`)
   - **Gambar**: Thumbnail artikel (800x600 px recommended)
   - **Kategori**: Competition / Announcement / News
   - **Isi Konten**: Ketik artikel lengkap di sini
   - **Penulis**: Nama Anda
4. Klik **"Publikasikan"**

---

### Menu 3: Competition
**Pokoknya: Kelola kompetisi dan pendaftaran**

#### Komponen Kompetisi:
- **Nama**: Judul kompetisi (contoh: "Wedding Planner Competition 2026")
- **Target**: Siapa boleh ikut (Wedding Planners, Designers, Students, dll)
- **Hadiah**: Total prizes (contoh: "Rp 200 Juta")
- **Deadline**: Tanggal terakhir pendaftaran
- **Persyaratan**: List requirements peserta
- **Status**: Open / Coming Soon / Closed

#### Cara Buat Kompetisi Baru:
1. Menu **Competition** > **All Competitions**
2. Klik **"+ Buat Kompetisi"**
3. Isi data kompetisi
4. Jika sudah open, status diubah menjadi **Open**

---

### Menu 4: Featured Events
**Pokoknya:Gambar keren di bagian atas website (CardStack)**

#### Cara Update Featured Events:
1. Menu **Featured Events**
2. Klik **Edit** pada kartu yang ingin diubah
3. Bisa ubah:
   - **Gambar**: Upload foto baru
   - **Judul**: Nama event
   - **Deskripsi**: Posting pendek
   - **Order**: Drag & drop untuk urutkan card
   - **Rotation**: Sudah otomatis (tidak perlu diubah)

---

### Menu 5: Settings
**Pokoknya: Pengaturan akun & umum**

#### Sub-menu Settings:
- **Change Password**: Ganti password login
- **Background Music**: Upload lagu untuk background player
- **Contact Info**: Update email, nomor telepon, alamat
- **Social Media**: Link Instagram, Facebook, LinkedIn

## 4. Upload Gambar - Panduan Lengkap

### Spesifikasi Gambar yang Diperlukan:

| Tujuan | Ukuran Recommended | Format | Max Size |
|--------|-------------------|--------|----------|
| Portfolio Thumbnail | 800x600 px | JPG/PNG | 5MB |
| Hero Section | 1920x1080 px | JPG/PNG | 5MB |
| News Thumbnail | 800x400 px | JPG/PNG | 5MB |
| Featured Card | 600x800 px | JPG/PNG | 5MB |

### Cara Upload Gambar:

#### Opsi 1: Upload di Menu Portfolio/News
- Langsung pilih file saat form isian
- Gambar otomatis tersimpan di folder yang benar

#### Opsi 2: Upload Manual di Media Library
1. Menu **Media** > **Library**
2. Klik **"Upload New"**
3. Pilih file
4. Setelah upload, copy URL gambar (klik "Copy URL" atau lihat di kolom URL)

## 5. FAQ - Troubleshooting

### "Gambar tidak muncul setelah upload"
- Cek ukuran file (max 5MB)
- Cek format (JPG/PNG/WebP saja)
- Refresh browser (Ctrl+F5)

### "Data tidak terupdate di website"
- Tunggu 1-2 menit (system cache)
- Refresh website dengan Ctrl+F5
- Cek status:Published (untuk News)

### "Lupa password"
- Klik "Forgot Password" di halaman login
- Masukkan email admin
- Cek inbox email untuk link reset password

### "Tidak bisa upload gambar"
- Pastikan internet stabil
- Coba format gambar lain (ubah ke JPG)
- Kompres gambar sebelum upload

### "Ganti email login"
- Hubungi tim developer
- Minta update email admin di database
