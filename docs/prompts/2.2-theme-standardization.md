# Prompt 2.2: Theme Color Standardization

## Role
You are a **UI/UX Designer** and **Tailwind CSS Expert**. Your task is to standardize the theme colors across the entire project for consistency.

---

## Context

**Project:** KATH Event Organizer - Landing Page & Competition Platform
**Current Issue:** Theme inconsistency between documentation and implementation

---

## Problem Statement

### Documentation Says (info.md, AGENT_COLLABORATION.md)

**Bright & Premium Theme (Blue + Gold)**
- Primary: `#3B82F6` (Vibrant Blue - Trust)
- Accent: `#F59E0B` (Warm Gold - Premium)
- Background: `#F8FAFC` (Light)
- Text: `#0F172A` (Dark)

### Implementation Has (tailwind.config.js)

**Premium Gold & Black Theme**
- Primary: `#AE8E1C` (Gold)
- Background: `#FAFAFA` (Light gray)
- Text: `#1A1A1A` (Dark)

---

## Decision Required

### Choose ONE Theme

**Option A: Bright & Premium (Blue + Gold)** ⭐ RECOMMENDED

**Why:**
- More modern and professional
- Blue = Trust (perfect for competition platform)
- Gold = Premium/Excellence (maintains luxury feel)
- Better contrast and accessibility (WCAG AA compliant)
- Matches international competition standards

**Color Psychology:**
- Blue: Trust, professionalism, stability
- Gold: Excellence, premium, achievement
- White: Clean, modern, spacious
