## Constraints

### Mandatory Rules (MUST)

1. **Accessibility:**
   - All text meets WCAG 2.1 AA contrast (4.5:1 minimum)
   - Focus states visible on all interactive elements
   - No information conveyed by color alone

2. **International Appeal:**
   - Colors appropriate across cultures
   - Typography supports multiple languages
   - Icons are universally understood

3. **Consistency:**
   - Same design language across all touchpoints
   - Consistent spacing system (8px grid)
   - Unified component library

### Prohibited Actions (MUST NOT)

1. **Don't:**
   - Use more than 5 primary colors
   - Mix incompatible design styles
   - Use emoji as icons
   - Rely on trends that will date quickly

2. **Avoid:**
   - Overly complex designs
   - Text-heavy layouts
   - Low contrast combinations
   - Inconsistent spacing
