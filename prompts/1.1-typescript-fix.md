## Issues to Fix

### Issue 1: Missing Property in Config ⚠️

**File:** `src/sections/Competition.tsx`
**Line:** 263
**Error Code:** TS2339

**Error Message:**
```
Property 'totalPrize' does not exist on type '{ name: { id: string; en: string; }; deadline: string; description: { id: string; en: string; }; }'
```

**Current Code:**

**Root Cause:**
