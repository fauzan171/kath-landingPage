### Task 2: Reorganize Components

**Step 1: Create New Folders**

```bash
mkdir -p src/components/common
mkdir -p src/components/layout
mkdir -p src/config
mkdir -p src/types
```

**Step 2: Move Files**

```bash
# Move BackgroundMusic
mv src/components/BackgroundMusic.tsx src/components/common/BackgroundMusic.tsx

# Move LanguageSwitcher (if it's a common component)
mv src/components/LanguageSwitcher.tsx src/components/common/LanguageSwitcher.tsx

# Move layout components (if separated)
# mv src/sections/Navigation.tsx src/components/layout/Header.tsx
# mv src/sections/Footer.tsx src/components/layout/Footer.tsx
```

**Step 3: Update Imports**

Find all files importing from old paths:

```bash
# Search for imports
grep -r "from './components/BackgroundMusic'" src/
grep -r "from '../components/BackgroundMusic'" src/
grep -r "from '@/components/BackgroundMusic'" src/
```

Update to new paths:
```typescript
// Before
import BackgroundMusic from './components/BackgroundMusic';

// After
import BackgroundMusic from './components/common/BackgroundMusic';

// OR with alias
import BackgroundMusic from '@/components/common/BackgroundMusic';
```

### Task 3: Remove Duplicate Routes

**File:** `src/App.tsx`

```typescript

  <Route path="/" element={<LandingPage />} />
```
