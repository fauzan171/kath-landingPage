## COLOR SYSTEM METHODOLOGY

### Step 1: Define Color Personality
```
Questions to ask:
- What emotion should the brand evoke?
- Who is the target audience?
- What industry is this for?
- What are competitor colors?
- Any cultural considerations?
```

### Step 2: Primary Color Selection
```
Process:
1. Start with color psychology alignment
2. Test against 10+ competitor colors
3. Verify accessibility (contrast)
4. Test on multiple backgrounds
5. Validate in light/dark modes
```

### Step 3: Build Color Palette
```
For each primary color, generate:
- 50-100: Lightest tints
- 200-300: Light tints
- 400: Light variant
- 500: Base color
- 600: Dark variant
- 700-900: Darker shades
```

### Step 4: Semantic Colors
```
Define:
- Success: Green shades
- Warning: Yellow/Orange shades
- Error: Red shades
- Info: Blue shades
- Neutral: Gray scale
```

### Step 5: Validation
```
Test:
- WCAG contrast ratios
- Color blindness simulation
- Cultural appropriateness
- Print rendering (if applicable)
- Dark mode variants
```

## TYPOGRAPHY SYSTEM METHODOLOGY

### Font Selection Criteria

#### For Headings
```
Criteria:
- Distinctive character
- Good readability at large sizes
- Available weights (300-900)
- Web font performance
- Multi-language support
```

#### For Body Text
```
Criteria:
- Excellent readability at 14-18px
- Clear letterforms (no confusion: l/1/I, O/0)
- Good x-height
- Comfortable reading on screens
- Performance (font loading)
```

### Pairing Strategy

#### Method 1: Contrast
```
Serif heading + Sans-serif body
or
Display heading + Neutral body
```

#### Method 2: Harmony
```
Same font family, different weights
or
Fonts from same designer
```

#### Method 3: Hierarchy
```
One font, multiple weights
Size and weight create hierarchy
```

## SPACING SYSTEM

### The 8px Grid
```
Why 8px?
- Divisible by 2 and 4 (halving)
- Works across devices
- Common in design tools
- Aligns with browser defaults

Base: 8px
Scale: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 128
```

### Application Rules

#### Internal Spacing (Component)
```
Button padding: 8px 16px
Input padding: 12px 16px
Card padding: 24px
Modal padding: 32px
```

#### External Spacing (Layout)
```
Section gap: 64px-128px
Element gap: 16px-32px
Inline gap: 8px-16px
```

## COMMUNICATION STYLE

### Design Rationale Template
```
"I chose [design decision] because:

1. **User Evidence**: [Research/testing data]
2. **Best Practice**: [Industry standard/pattern]
3. **Accessibility**: [WCAG compliance]
4. **Consistency**: [Design system alignment]
5. **Business Goal**: [Metric it supports]

Alternatives considered:
- Option A: [Why not chosen]
- Option B: [Why not chosen]
"
```

### Feedback Delivery
```
Good: "The button color doesn't meet WCAG contrast requirements.
       Using a darker shade (#1D4ED8 instead of #3B82F6) would
       increase contrast from 3.5:1 to 5.2:1, making it accessible
       for users with low vision."

Avoid: "The button color is wrong."
```

### Question Framework
```
Clarifying questions:
- "What problem are we solving?"
- "Who is this for?"
- "What constraints exist?"
- "How will success be measured?"
- "What's the timeline?"

Validation questions:
- "Does this align with user needs?"
- "Is this accessible?"
- "Can this be implemented?"
- "Is this maintainable?"
```

## INTERNATIONAL EXPERIENCE INSIGHTS

### Cultural Considerations

#### Color Meanings by Region
```
Red:
- Western: Danger, passion, stop
- China: Luck, prosperity, joy
- India: Purity, fertility
- South Africa: Mourning

White:
- Western: Purity, peace
- Asia: Death, mourning
- India: Unhappiness

Blue:
- Universal: Trust, professional
- Generally safe across cultures
```

#### Layout Preferences
```
RTL Languages (Arabic, Hebrew):
- Mirror entire layout
- Icons can remain LTR
- Consider text expansion

Asian Languages:
- More vertical space for text
- Different font requirements
- Consider input methods
```

#### Reading Patterns
```
Western: F-pattern, Z-pattern
RTL: Reversed patterns
Asian: Different scanning behavior
```
